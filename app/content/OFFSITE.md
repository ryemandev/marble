# Search: the owner's off-site list

The site does the on-page work (pages, structured data, sitemap, IndexNow, llms.txt). These steps need the owner's own accounts, so only the owner can do them.

## The facts to use everywhere

Copy these word for word, so Google, AI tools and every listing say the same thing.

- **Name:** Marble.
- **Title:** Free Trading Journal for Prop & Personal Accounts | Marble
- **One line:** Stop paying to build better habits. Marble is the free trading journal with every feature: import or log trades, see your total P&L, track prop firm rules.
- **Main line:** Stop paying to build better habits.
- **Short line for bios:** Stop paying to build better habits. The free trading journal.
- **Website:** https://trademarble.app
- **Price:** free forever, every feature, for everyone. No card, no trial and no plans, so never list a price or a paid tier.
- **Logo for socials, Google and link previews:** the small m favicon, `public/brand/marble-icon-1024.png` (the live copy is https://trademarble.app/icon-512.png). Use it for every profile picture, listing icon and app icon.
- **Logo for the website and app only:** the big Marble wordmark. Don't use it as a profile picture or a listing icon.
- **Link preview picture:** https://trademarble.app/og.jpg?v=4. If a site still shows an old preview, run the page through its link checker again (X's and Facebook's both have one).

## This week

1. **Google Search Console.** Add trademarble.app as a domain property. The domain is on Cloudflare, so Search Console can verify it through Cloudflare in one click. Then submit `https://trademarble.app/sitemap.xml` and ask for indexing of `/`, `/prop-firms/` and `/guides/`. If it offers an HTML tag instead, send Claude the code and it goes in `.env` as `VITE_GSC_VERIFY`.
2. **Bing Webmaster Tools.** Sign in and import the site from Search Console. Bing's index also feeds ChatGPT search, Copilot and DuckDuckGo. IndexNow already tells Bing about every deploy.
3. **Profiles link home.** The X, Instagram and YouTube bios each link to trademarble.app, with the small m as the profile picture and the short line above, the same everywhere.

## This month

4. **Free listings, each a real mention and link:** Product Hunt (a proper launch day), AlternativeTo (as an alternative to Tradezella, TraderSync, Tradervue and Edgewonk), SaaSHub, G2, Capterra, Crunchbase, BetaList and Indie Hackers. Each one gets the title, the one line, the small m and "free" as the price from the facts above.
5. **Reviews from real users only**, on Trustpilot or G2. Never paid, swapped or written by us.
6. **Share each week's best page where traders already ask the question.** On Reddit (r/FuturesTrading, r/Daytrading, r/Forex) and Discord servers, as a helpful answer that follows each community's rules, not as an ad. Link the matching page in the YouTube descriptions.
7. **Others link to us.** Trading educators and prop firm communities can link a guide or firm page their audience needs.

## Ongoing

8. **Mentions in the press:** Qwoted and Featured for journalist questions, guest posts on trading blogs, podcast guest spots.
9. **Read Search Console every few weeks.** Pages getting impressions but few clicks get better titles; questions people search that no page answers go into the next batch.

## Never

Bought links, link farms or swaps at scale, fake or paid reviews, keyword stuffing, hidden text, pages shown differently to Google, or mass-produced pages written to rank rather than to help. Each of these breaks Google's spam policies and can sink the whole site.

## What to expect

Searches for the name ("trademarble", "marble trading journal") usually start showing the site within days to a few weeks of Search Console. Firm-rules searches take weeks to a few months. "Trading journal" on its own is the hardest, and it moves with links from other sites more than with page count. "Marble" on its own mostly means stone, so the site won't rank for that word alone.
